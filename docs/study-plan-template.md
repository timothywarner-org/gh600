# Study plan template

Pick the schedule that fits your calendar, copy it into your planner, and protect the time. Each one comes to about 32 hours.

## 30-day sprint (4 weeks, about 8 hours per week)

| Week | Lessons | Focus |
| --- | --- | --- |
| 1 | 1, 2 | Agent architecture, planning, and repository governance. Set up a sandbox organization and a practice repository. |
| 2 | 3, 4 | Agent tools, MCP servers, and execution context. Run your first Copilot cloud agent session. |
| 3 | 5, 6 | Memory and state, then evaluation and tuning. Turn on code scanning in your practice repository. |
| 4 | 7, 8, 9 | Multi-agent coordination, guardrails, and exam readiness. Work practice questions and schedule your exam. |

## 60-day plan (8 weeks, about 4 hours per week)

| Week | Lessons | Focus |
| --- | --- | --- |
| 1 | 1 | Agents in the software lifecycle, structured plans, and approval gates |
| 2 | 2 | Pull request governance, rulesets, and agent scope |
| 3 | 3 | Agent tools, MCP servers, registries, and allow lists |
| 4 | 4 | Execution context, CI workflows, cloud agent sessions, and error handling |
| 5 | 5 | Memory strategies, durable state, and context drift |
| 6 | 6 | Evaluation signals, failure analysis, and tuning |
| 7 | 7 | Orchestration, isolation, conflicts, and recovery across agents |
| 8 | 8, 9 | Guardrails and accountability, then exam readiness and practice questions |

## 90-day plan (13 weeks, about 2.5 hours per week)

Spread the 60-day plan over the first 11 weeks, one lesson per week with an extra week wherever your ratings run lowest, then add:

- **Week 12:** A cross-lesson lab. Carry one issue from assignment to merged pull request: a custom agent plans the work, a ruleset gates the merge, the scanners grade the change, and the agent's commits and logs show who did what.
- **Week 13:** Practice questions across every domain, with a full review of every miss against the [exam objective map](exam-objectives.md).

## Every study week

Touch each of these:

1. **Theory:** the video lessons, GitHub Docs, Microsoft Learn, and the official study guide
2. **Hands-on experience:** the lab files in this repository, in your own sandbox organization
3. **Practice questions:** attempts with a debrief of every miss. The [certification page](https://learn.microsoft.com/credentials/certifications/agentic-ai-developer/) listed no free practice assessment for GH-600 when this page was checked on November 14, 2026.

Skip one and your retention drops. Done beats perfect.
