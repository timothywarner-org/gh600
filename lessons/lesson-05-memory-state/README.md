# Lesson 5: Manage Memory, State, and Execution

**Exam GH-600 domain:** Manage memory, state, and execution (10-15%)

## Learning objectives

Each objective is word for word from the course outline. Under it are the study guide skills it serves, with the IDs from the [exam objective map](../../docs/exam-objectives.md).

- 5.1 Choose between short-term, long-term, and external memory
  - Skill 3.1.1: Choose between short-term, long-term, and external memory
- 5.2 Scope memory to task-relevant information and share state across tools and environments
  - Skill 3.1.2: Scope agent memory to task-relevant information
  - Skill 3.3.1: Share agent state
- 5.3 Persist task progress and decisions as durable state
  - Skill 3.2.1: Capture task progress and decisions as durable artifacts
- 5.4 Resume interrupted work without repeating completed steps or diverging from prior decisions
  - Skill 3.2.2: Resume agent work without repeating steps or diverging from prior decisions
- 5.5 Configure Copilot Memory and distinguish repository facts, user preferences, and administrator policies
  - Skill 3.1.1: Choose between short-term, long-term, and external memory
- 5.6 Apply memory expiration, validation, pruning, and reset strategies
  - Skill 3.1.3: Define memory expiration, pruning, and reset rules
  - Skill 3.3.3: Prevent stale context
- 5.7 Detect and correct drifting, stale, and conflicting context
  - Skill 3.2.3: Detect and correct drift during extended agent execution
  - Skill 3.3.2: Prevent conflicting context
  - Skill 3.3.3: Prevent stale context

## Study guide skill groups

- Implement agent memory strategies
- Persist agent state and manage context drift
- Ensure continuity of agent memory and state across tools and environments

Lab files for this lesson arrive when the lesson publishes. Its [`demos/`](demos/) page will list them in run order, and the files will live in [`lab/`](../../lab/). Do the [one-time lab setup](../../lab/README.md) now, so you're ready when they land.
