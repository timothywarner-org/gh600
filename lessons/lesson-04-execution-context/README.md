# Lesson 4: Tool Use Part 2 - Execution Context and Safe Execution Paths

**Exam GH-600 domain:** Implement tool use and environment interaction (20-25%)

## Learning objectives

Each objective is word for word from the course outline. Under it are the study guide skills it serves, with the IDs from the [exam objective map](../../docs/exam-objectives.md).

- 4.1 Evaluate execution context: repository, branch, workflow, runner, and sandbox
  - Skill 2.3.1: Evaluate the execution context for an agent
- 4.2 Invoke agents from CI workflows and cloud-agent sessions
  - Skill 2.3.3: Configure an agent to be invoked in a CI workflow
- 4.3 Enable autonomous branch and pull-request creation under branch-based scope
  - Skill 2.3.4: Configure an agent to use branch-based scope
  - Skill 2.3.5: Enable an agent to perform autonomous actions, including creating branches and pull requests
- 4.4 Implement error handling, retries, rollbacks, and escalation paths
  - Skill 2.4.1: Implement error handling
  - Skill 2.4.2: Implement retries
  - Skill 2.4.3: Implement rollbacks
  - Skill 2.4.4: Implement escalation paths
- 4.5 Handle environment-specific constraints: secrets, variables, setup steps, and network access
  - Skill 2.3.6: Configure an agent to handle environment-specific constraints

## Study guide skill groups

- Integrate agents within development environments
- Operate agents with safe execution paths and robust error handling

## Hands-on practice

Lab files for this lesson arrive when the lesson publishes. Its [`demos/`](demos/) page will list them in run order, and the files will live in [`lab/`](../../lab/). Do the [one-time lab setup](../../lab/README.md) now, so you're ready when they land.

Copilot agents rarely produce the same wording twice, so your results will read differently from the video. Look for the same outcome: the plan, the branch, the pull request, the blocked action, or the log entry.

## Before you start

- The accounts and tools in the [one-time lab setup](../../lab/README.md).
- Copilot cloud agent turned on for your practice repository. It's available on all paid Copilot plans. On Copilot Business and Copilot Enterprise, an administrator turns it on through policy first.
- Each Copilot cloud agent session uses GitHub Actions compute and your Copilot plan's usage allowance, so set a budget before you start (GitHub Docs, checked November 14, 2026).
