# Lesson 7: Orchestrate Multi-Agent Coordination

**Exam GH-600 domain:** Orchestrate multi-agent coordination (15-20%)

## Learning objectives

Each objective is word for word from the course outline. Under it are the study guide skills it serves, with the IDs from the [exam objective map](../../docs/exam-objectives.md).

- 7.1 Apply orchestration patterns to coordinate multiple agents
  - Skill 5.1.1: Apply an orchestration pattern to coordinate multiple agents
- 7.2 Build a working Copilot SDK researcher-and-editor sub-agent pair
  - Skill 5.1.1: Apply an orchestration pattern to coordinate multiple agents
- 7.3 Isolate agents for parallel execution and scope tools and MCP servers per agent
  - Skill 5.1.2: Configure agent isolation for parallel execution
- 7.4 Capture events, decisions, handoffs, and outcomes as reviewable artifacts for audit and post-hoc analysis
  - Skill 5.2.1: Configure multi-agent workflows to produce artifacts suitable for review and audit
  - Skill 5.2.2: Document key decisions, handoffs, and outcomes across agents
  - Skill 5.2.3: Perform post-hoc analysis of multi-agent behavior
- 7.5 Detect and resolve overlapping changes, duplicated work, and contradictory outputs
  - Skill 5.1.3: Detect and resolve agent conflicts, including overlapping code changes, duplicated effort, and contradictory outputs
- 7.6 Detect failed, partial, stalled, and degraded agent execution or coordination
  - Skill 5.3.1: Identify failed, partial, or stalled agent executions
  - Skill 5.3.2: Respond to degraded behavior or coordination across agents
- 7.7 Recover with retries, rollback, recoordination, and human intervention
  - Skill 5.3.2: Respond to degraded behavior or coordination across agents
  - Skill 5.3.3: Implement multi-agent recovery patterns, including rollback and human-in-the-loop
- 7.8 Add, update, reconfigure, replace, and retire agents while preserving auditability and workflow continuity
  - Skill 5.4.1: Add agents to existing multi-agent workflows
  - Skill 5.4.2: Update, reconfigure, or replace agents without disrupting active workflows
  - Skill 5.4.3: Retire agents while preserving auditability and workflow continuity

## Study guide skill groups

- Operate and manage multi-agent workflows
- Configure observability for multi-agent behavior by using logs, artifacts, and operational signals
- Detect and respond to multi-agent failures and degraded behavior
- Manage the lifecycle of agents within multi-agent workflows

## Hands-on practice

Lab files for this lesson arrive when the lesson publishes. Its [`demos/`](demos/) page will list them in run order, and the files will live in [`lab/`](../../lab/). Do the [one-time lab setup](../../lab/README.md) now, so you're ready when they land.

Copilot agents rarely produce the same wording twice, so your results will read differently from the video. Look for the same outcome: the plan, the branch, the pull request, the blocked action, or the log entry.
