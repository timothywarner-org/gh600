# Shared demos

This folder will hold demo material that spans more than one lesson. Each lesson's own files will be listed on that lesson's `demos/` page, for example [`lessons/lesson-03-tools-mcp-servers/demos/`](../lessons/lesson-03-tools-mcp-servers/demos/), and the files themselves will live in [`lab/`](../lab/).

## What is here now

Nothing yet. Shared material arrives with the first lesson that uses it, and the [changelog](../CHANGELOG.md) records when.

## How the lab files will work

- **GitHub.com and Visual Studio Code first.** Most steps happen where agents do their work. Command-line steps are there when the UI can't do the job.
- **Your values, in one place.** Every organization, repository, and account name sits behind a placeholder you fill in once.
- **Explained, not black box.** Every file starts with help that says what it reads and what it changes.
- **Least privilege.** Workflows grant `GITHUB_TOKEN` only the permissions each job needs, and tokens never appear in a file.
- **Cleanup at the end.** Every lesson that changes organization settings or uses billable time says how to undo it.
- **Fictional data.** Contoso, Ltd. and its people are made up. See [NOTICE.md](../NOTICE.md).
